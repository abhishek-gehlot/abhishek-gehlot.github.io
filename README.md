# Abhishek Gehlot — Portfolio

A responsive personal portfolio built with HTML, CSS, and vanilla JavaScript.

## Files
- `index.html` — page content
- `style.css` — responsive layout and styling
- `script.js` — mobile navigation and copy-email interaction

## Before publishing
1. Open `index.html`.
2. Replace `ADD_YOUR_EMAIL_HERE` with your professional email.
3. Verify each project description and add the exact Chatting Application repository URL.
4. Confirm the internship wording and add accurate dates/responsibilities if desired.
5. Test the page on mobile and desktop.

## Run locally
Open `index.html` in a browser.

## Publish free with GitHub Pages
1. Create a GitHub repository named `abhishek-gehlot.github.io` (or another repo for a project site).
2. Upload `index.html`, `style.css`, and `script.js` to the repository root.
3. In the repository, open **Settings → Pages**.
4. Choose **Deploy from a branch**, select `main` and `/ (root)`, then Save.
5. Wait for GitHub Pages to publish and open the provided URL.
